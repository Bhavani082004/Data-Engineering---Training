           Document Design
68. Product can have five colors.

Design Choice: Array
Reason: An array stores multiple colors in one field.
Example:

colors: ["Black", "White", "Red", "Blue", "Grey"]
69. Customer has one residential address.

Design Choice: Embedded Document
Reason: An embedded document stores related address details together.

Example:

address: {
  city: "Chennai",
  state: "Tamil Nadu",
  pincode: "600028"
}
70. Order contains multiple products.

Design Choice: Array of Embedded Documents
Reason: Each product can have its own name, quantity, and price.

Example:

items: [
  { product: "Laptop", quantity: 1, price: 72000 },
  { product: "Mouse", quantity: 2, price: 2000 }
]
71. Product has RAM, storage, and processor information.

Design Choice: Embedded Document
Reason: Related product specifications can be grouped together.

Example:specifications: {
  RAM: "16 GB",
  storage: "1 TB SSD",
  processor: "Intel i7"
}
72. Customer can have thousands of orders over many years.

Design Choice: Separate Collection / Reference
Reason: Storing orders separately prevents the customer document from growing too large.

73. Product can have millions of customer reviews.
Design Choice: Separate Collection / Reference
Reason: A separate reviews collection can manage a very large number of reviews efficiently.

74. Employee has first name and last name.

Design Choice: Simple Field
Reason: First name and last name are individual values.

Example:first_name: "Ravi",
last_name: "Kumar"

75.Product has multiple tags.
Design Choice: Array
Reason: An array stores multiple tags in one field.

Example:

tags: ["Electronics", "Laptop", "Office"]

85.Explain briefly why you used:
1. Array for categories:
   An array stores multiple product categories in a single field.

2. Embedded document for contact details:
   An embedded document groups related contact information, such as person, phone number, and email, together.

3. Array for warehouse locations:
   An array stores multiple warehouse locations for each supplier in one field.
